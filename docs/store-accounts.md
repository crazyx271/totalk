# Аккаунты магазинов ToTalk

## Apple Developer Program

Регистрация: https://developer.apple.com/programs/enroll/

- Цена: 99 USD ежегодно, либо локальная цена Apple для региона.
- Для физического лица нужны Apple Account с 2FA, совершеннолетие, настоящее имя, адрес, телефон и документ для проверки личности.
- Для организации дополнительно нужны зарегистрированное юридическое лицо, сайт, D-U-N-S Number и право подписывать договоры от имени организации.
- У индивидуального аккаунта в App Store отображается настоящее имя владельца. Название компании отображается только при регистрации организации.

После активации создайте App ID `com.totalk.mobile`, включите Push Notifications, создайте приложение ToTalk в App Store Connect и добавьте GitHub Secrets из README мобильного проекта.

## Google Play Console

Регистрация: https://play.google.com/console/signup

- Цена: 25 USD однократно.
- Нужны Google Account, совершеннолетие, платёжная карта, телефон, адрес и документ для проверки личности.
- Для организации нужен D-U-N-S Number и данные юридического лица.
- Новый личный аккаунт должен провести закрытый тест минимум с 12 тестировщиками в течение 14 непрерывных дней перед запросом production-доступа.

После активации создайте приложение с package name `com.totalk.mobile`, включите Play App Signing и подготовьте Firebase-проект с Android package `com.totalk.mobile` для push-уведомлений.

## Что можно сделать до оплаты

- Android APK можно собирать и устанавливать напрямую без Play Console.
- iOS-приложение можно запускать на собственном устройстве через Xcode с бесплатным Apple Account, но публикация, TestFlight и полноценные push-возможности требуют платной программы.
- macOS DMG без сертификата можно собрать, но для нормального запуска у пользователей нужны Developer ID signing и notarization.
